# Areas/

## 목적
마감일 없이 지속적으로 유지·관리해야 하는 삶의 영역. 끝나지 않는다.

## 들어가는 노트
- 역할 기반 책임 (개발자로서 성장, 건강 관리, 재정 관리 등)
- 정기적으로 검토하고 업데이트하는 기준·원칙·습관 노트
- 특정 프로젝트에 속하지 않는 진행형 학습 기록

## 영역 예시
- `개발` — 기술 성장 방향, 학습 로그
- `건강` — 병원 기록, 운동·식단 루틴
- `재정` — 월 지출 관리, 목표 저축액
- `커리어` — 포트폴리오 방향, 자기계발 계획

## 규칙
- 영역별 하위 폴더 1개씩 생성
- 각 영역 폴더에 `_overview.md`로 현재 상태·목표·정기 검토 주기 기록
- 프로젝트로 발전하면 Projects/로 이동, 단순 참고 자료는 Resources/로 분리
- 월 1회 전체 영역 검토
