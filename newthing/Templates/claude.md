# Templates/

## 목적
반복적으로 만드는 노트 유형의 틀 모음. 새 노트 작성 시 복사해서 시작한다.

## 들어가는 파일
- `tpl-project.md` — 프로젝트 개요 템플릿
- `tpl-literature.md` — 원천 자료 정리 템플릿
- `tpl-permanent.md` — 영구 지식 노트 템플릿
- `tpl-meeting.md` — 회의록 템플릿
- `tpl-daily.md` — 일일 메모 템플릿 (선택)

## 규칙
- 파일명 접두사: `tpl-`
- 템플릿 자체는 수정만 하고 삭제하지 않는다
- Obsidian Templater 플러그인 사용 시 이 폴더를 Template folder로 지정
