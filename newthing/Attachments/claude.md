# Attachments/

## 목적
노트에 삽입되는 모든 첨부 파일 보관소. Obsidian이 이미지·PDF 등을 자동으로 여기 저장하도록 설정한다.

## 들어가는 파일
- 노트에 붙여넣은 이미지 (스크린샷, 다이어그램)
- 참조용 PDF
- 드래그앤드롭으로 첨부된 파일

## Obsidian 설정
`Settings → Files & Links → Default location for new attachments` → `In the folder specified below` → `Attachments`

## 규칙
- 직접 파일을 만들거나 정리하지 않아도 된다 — Obsidian이 자동 관리
- 노트가 Archive로 이동해도 첨부 파일은 이곳에 그대로 유지 (링크 깨짐 방지)
- 주기적으로 사용하지 않는 파일 정리 시 Obsidian의 "Detect unused attachments" 기능 활용
