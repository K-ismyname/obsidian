# Zettelkasten/00. Inbox/

## 목적
생각이 날 때마다 즉시 던져두는 수거함. 완성도보다 속도가 우선.
모든 노트는 Inbox에서 시작한다.

## 들어가는 노트
- 갑자기 떠오른 아이디어·질문
- 빠르게 캡처한 링크·인용문
- 아직 어디 넣을지 모르는 메모

## 작업 방식
1. **캡처**: 생각 나는 즉시 파일 하나 만들고 내용만 적는다. 제목·태그 나중에.
2. **정리 (주 1회)**: Inbox를 비운다 — Literature로 발전시키거나, Permanent로 바로 올리거나, 버린다.

## 규칙
- Inbox가 20개를 넘으면 반드시 정리한다
- 여기 오래 머무는 노트는 없어야 한다 — 최대 1주일
- 파일명 형식: `YYYYMMDD 제목 (초안)` 또는 그냥 떠오르는 대로
