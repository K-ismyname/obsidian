# Zettelkasten/20. Permanent/

## 목적
Zettelkasten의 핵심. 하나의 아이디어 = 하나의 노트.
출처와 무관하게 **내가 이해하고 내 말로 쓴** 영구 지식 단위.

## 들어가는 노트
- 단일 개념·아이디어를 설명하는 원자 단위 노트
- 여러 Literature 노트를 종합해 도출한 통찰
- 시간이 지나도 변하지 않는 원칙·패턴

## 작업 방식
1. **하나의 노트 = 하나의 아이디어** — 너무 길면 분리한다
2. 완전한 문장으로 작성 — 나중에 맥락 없이 읽어도 이해되어야 한다
3. 관련 Permanent 노트끼리 `[[링크]]`로 연결 — 연결이 많을수록 가치가 높다
4. Literature 출처가 있으면 하단에 참조 기록

## 규칙
- 파일명: `ZK-YYYYMMDD 핵심 주장 한 문장`
  - 예: `ZK-20260604 Zettelkasten은 연결의 밀도로 가치가 결정된다`
- 완성도 기준: "이 노트만 읽어도 아이디어가 전달되는가?"
- 한 번 쓴 노트는 지우지 않고 업데이트한다 (날짜 갱신)
