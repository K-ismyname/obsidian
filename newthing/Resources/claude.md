# Resources/

## 목적
특정 프로젝트나 영역에 묶이지 않는 주제별 참고 자료 라이브러리.
"나중에 쓸 것 같아서" 모아두는 공간.

- 기술 문서, 튜토리얼 요약
- 책·아티클·영상 핵심 내용 정리
- 반복적으로 참조하는 개념 설명
- 도구·라이브러리·서비스 사용법 메모

## 규칙
- 주제별 하위 폴더 분류 (예: `Claude Code`, `FastAPI`, `이민 도메인`)
- 날짜보다 **주제** 중심으로 정리
- Zettelkasten/10. Literature에서 충분히 다듬어진 자료를 여기로 승격
