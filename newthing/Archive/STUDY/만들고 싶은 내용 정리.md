## 2. 이민 프로세스

### 사전 준비 (우선순위 날짜를 받기 전까지 갖춰야 할 3가지)

**① NCLEX 시험 패스**

- 미국 간호사 면허 시험
- → 서비스에서 **시험 날짜 알림** 제공

**② 영어 시험 → CGFNS 제출 (VisaScreen)**

- IELTS / TOEFL / PTE 중 하나 제출
- **CGFNS** = 모든 이민 서류 프로세스를 담당하는 기관 (예: 학교 학력 입증 등)
- → **이메일 연동** 기능
- 메모: _고객센터 응대가 매우 좋지 않음_ → 후기 공유 필요

**③ Agency 찾기**

- 특정 병원 취업과 연결해 데려오는 역할
- agency 정보는 **폐쇄적이라 공유가 어려움**, 공유 시 **고소 이슈**가 있었던 만큼 취급 주의

### Step 1 — I-140 승인 → 우선순위 날짜(PD) 발급

위 3가지가 준비되면 **I-140(첫 번째 서류)** 제출, 승인되어야 **우선순위 날짜(PD)**가 나옴

- **I-140이란**: agency가 결정한 병원이 멀쩡한지(고용 능력이 있는지) 이민국이 검토하는 서류
- 제출 시 함께 내야 하는 서류가 있는데 **agency마다 다름**
- 흐름: 이민국 승인 → **fax로 서류 발송** → agency 변호사 수신 → 나에게 공유 (변호사가 중간에서 소통)

### 비자 불레틴 (Step 1 ↔ Step 2 사이의 대기·판단 구간)

- 출처: https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin.html
- **한 달에 한 번 발표** (보통 매월 10~15일)
- 표 구조
    - **가로 = 날짜**
    - **세로 = 등급(순위)** → _간호사는 3순위(3rd)_
    - **C(Current)** = 문호가 다 열린 상태
- 두 종류의 날짜
    - **FINAL ACTION DATES** = 대사관 인터뷰를 볼 수 있는 날짜
    - **DATES FOR FILING** = 서류를 제출할 수 있는 날짜
- 읽는 법: 내 **우선순위 날짜(PD)가 표에 적힌 날짜보다 앞설 때만** 진행 가능
    - 예) 내 PD가 2023년 1월 1일이면, 표의 해당 등급 날짜가 그 이후로 넘어와야 진행 가능
- 매달 조금씩 바뀌고, **전진했다가 후퇴(막힘)할 수도 있음**
- → 서비스 아이디어: **매달 발표된 날짜를 도식화**(얼마나 전진/후퇴했는지 시각화)

> 흐름: (서류 제출 가능) → 대사관 인터뷰. 단, **미국 내에서 진행하면 인터뷰 생략 가능**하므로 대부분의 한국 사람은 인터뷰를 거침.

### Step 2 — DS-260 제출 완료

agency(변호사)에게 서류 제출 완료 시 2단계 완료

- **DS-260이란**: 미국 이민국이 **나 자신을 검토**하는 서류 (범죄 경력, 신체검사, 가족 사항 등)
- 직접 작성하면 복잡하므로 **변호사가 작성해 보내라고 함**

> **대기 구간**: 이민국에서 연락 올 때까지 걸리는 시간이 사람마다 다름. 이유는 개인 history가 다르기 때문 + 전쟁 등 외부 이슈 영향 → 사람들이 "얼마나 걸리나" 궁금해하지만 **수치화는 사실상 무의미**.

### Step 3 — DQ (Document Qualified) 통과

- 서류 검증 통과 단계, **보통 2~4개월** 소요
- **이메일로 통보**
- 서류 문제로 못 받는 사람도 있음 → 이민국과의 "서류 지옥" → 잘 공유되지 않는 영역

### Step 4 — 대사관 인터뷰 (가장 큰 단계)

- 인터뷰 **날짜를 메일로 통보**
- 절차: **신체검사(인터뷰 전 한국 병원)** → 결과지 지참 → 인터뷰 → **그 자리에서 통과/불통과 통보** → 영주권 배달(약 1주일)
- _거절될 경우_ → (내용 비어 있음, 보완 필요)

### Step 5 — (완료 / 영주권 수령)

> 메모에 5단계 내용이 비어 있습니다. Step 4의 "영주권 배달"을 별도 단계로 볼지 확인 필요.
