# 7. Hook 으로 안전장치 걸고 git 정리, pr 자동 생성
* Hook 
특정 순간에 자동으로 실행되는 감시자 
```json
{
  "hooks": {
    "PreToolUse": [          ← "도구를 쓰기 직전에"
      {
        "matcher": "Bash",   ← "Bash(터미널 명령) 실행할 때만"
        "hooks": [
          {
            "type": "command",
            "command": "if git branch --show-current | grep -q '^main$';
                        then echo 'DENY: main 브랜치에 직접 작업 금지...'
                        && exit 1;
                        fi"
          }
        ]
      }
    ]
  }
}
```
