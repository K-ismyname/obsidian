## 지침 
- **코딩 전에 생각하기** — 가정을 명시하고, 불확실하면 멈추고 묻는다. 해석이 여러 개면 말없이 하나 고르지 않는다.
- **단순하게 먼저** — 문제를 푸는 최소 코드만. 요청 안 한 기능·추상화·유연성·불필요한 에러처리 금지. ("시니어가 과하다고 할까?" 테스트)
- **수술하듯 최소 변경** — 건드려야 할 것만. 안 망가진 것 리팩토링 금지, 기존 스타일 유지, 내가 만든 흔적만 정리.
- **검증 가능한 목표로 실행** — "버그 수정" 같은 모호한 작업을 "재현 테스트 짜고 통과시키기"처럼 검증 가능한 목표로 바꾼다.
- **끝내기 전 테스트** — 코드를 건드렸으면 "완료" 말하기 전에 테스트를 돌린다. 없으면 최소한 빌드 확인.
- **에러를 읽고 추측 안 하기** — 실패하면 실제 에러·로그를 직접 읽는다. 기억으로 "흔한 수정" 적용 금지.
- **한국어 출력** — 사용자가 한국어면 한국어로 답하고, 문장은 콜론이 아니라 마침표로 끝낸다. 새 파일 첫 줄엔 한국어 한 줄 역할 주석.
- **계획 + 진행 노트** — 사소하지 않은 작업은 계획과 `progress.md`(결정·근거 기록)를 남겨 다음 세션이 이어받게 한다.
- **의미 있는 커밋** — 논리 단위 하나가 끝나면 커밋. ("한 문장으로 설명되나?" 안 되면 쪼갠다)

## Commands
- `uv run uvicorn app.main:app --reload` — 로컬 실행

## Architecture
- `app/graph/` — LangGraph 정의. 진입점은 `build_graph()`.
- `app/retrievers/` — Qdrant 검색. 신규 retriever는 `BaseRetriever` 상속.
- `app/api/` — FastAPI 라우터. 비즈니스 로직 금지 (graph/retriever로 위임).
- 흐름: request -> `api` -> `graph.ainvoke()` -> retriever -> LLM -> response

  
>> 전역에 넣으면 안되는 규칙 
## Project conventions
- 모든 LLM 호출은 `app/llm/client.py`를 거친다. SDK 직접 호출 금지.
- 환경변수는 `app/config.py`의 `Settings`로만 접근. `os.getenv` 직접 사용 금지.
- 비동기 일관성: graph/retriever/api 전부 async. 동기 함수 섞지 말 것.

  
>> 꼭 지켜야하는 규칙 
## Gotchas
- Qdrant 컬렉션을 코드에서 생성하지 말 것 — `scripts/init_qdrant.py`로만 생성.
- 임베딩 모델을 바꾸면 벡터 차원이 달라져 기존 컬렉션과 충돌 -> 재인덱싱 필요.

- LangGraph 상태는 `TypedDict`. dict를 직접 수정하지 말고, 각 노드는 부분 업데이트만 반환.
