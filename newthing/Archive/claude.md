# Archive/

## 목적
완료·종료·비활성화된 모든 항목의 보관소. 삭제 대신 이곳으로 이동한다.

## 들어가는 노트
- 완료된 Projects/ 폴더 전체
- 더 이상 관리하지 않는 Areas/ 영역
- 오래되어 참조하지 않는 Resources/ 자료
- 종료된 스터디·강의 노트

## 규칙
- 이동할 때 파일명·내용을 수정하지 않는다 (맥락 보존)
- 폴더 구조: `Archive/Projects/`, `Archive/Areas/`, `Archive/Resources/`로 출처별 분리
- 보관 후 검색으로만 접근, 정기 정리 불필요
- **삭제는 하지 않는다** — 나중에 참고가 필요할 수 있다
